# Gamle migrasjoner (kun historikk)

Alt i denne mappen er **allerede bakt inn i `../schema.sql`**, som er den ene
filen du kjører for å sette opp `dart_vm`-skjemaet fra bunnen (se README →
«Database-tabeller»). Filene her er beholdt som dokumentasjon på *hvorfor*
ting ser ut som de gjør (kommentarene i hver fil), og for en database som ble
satt opp før `schema.sql` fantes. Ikke kjør dem på et nytt prosjekt.
